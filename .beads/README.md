# Задачи хакатона ОмГТУ, кейс №8

Для работы с задачами команда использует Beads. Префикс проекта - `omgtu8`. Перенос проверен на Beads 1.0.4.

После клонирования репозитория выполните из его корня:

```sh
bd bootstrap --yes
bd show omgtu8-mlu
bd ready
```

В `issues.jsonl` хранятся карточки с заметками, статусами, метками и зависимостями. В `interactions.jsonl` сохранены записи об изменениях статуса. Чтобы подготовить актуальный снимок после работы с задачами, выполните `bd export --all -o .beads/issues.jsonl` и включите изменения в коммит.
